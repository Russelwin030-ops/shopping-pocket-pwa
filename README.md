# 买买记 · 个人购物管理 PWA

纯前端、无账号、无服务器数据库。商品记录及图片使用浏览器 IndexedDB，仅保存在当前设备。

## 已实现

- 淘宝、京东、拼多多、抖音分享文本中的平台、链接、部分标题和价格提取
- 商品增删改查、分类、搜索、购买状态及数量
- 商品标价、会员价、优惠券、其他优惠、运费、手动覆盖预计实付
- 下单日期、实际付款、退款金额、订单编号、备注
- 首页、清单、按平台及月份统计
- 本地上传商品图片（压缩）、JSON 备份与恢复、CSV 导出
- iPhone 主屏幕安装清单文件、离线静态缓存

## 目前没有接入

- 淘宝、京东、抖音账号授权、个人优惠券读取、真实商品数据接口、订单自动同步
- iOS 购物 App 的原生分享扩展（iPhone 分享面板中不会自动出现此 PWA）
- 自动对复杂优惠叠加规则进行平台级验证

## 在 Windows 预览

在项目目录运行 `python -m http.server 8080`，电脑打开 `http://localhost:8080`。正式安装至 iPhone 必须部署到 HTTPS 网站（例如 GitHub Pages），访问地址后在 Safari 分享菜单选择「添加到主屏幕」。

## GitHub Pages 免费部署

1. 在 GitHub 创建公开仓库（请勿上传任何个人购物备份或账号凭证）。
2. 将本目录所有文件上传到仓库根目录。
3. 在仓库 Settings > Pages 中选择 Deploy from a branch，选择 main / (root)，保存。
4. 等待 GitHub 页面生成 HTTPS 地址，在 iPhone Safari 中打开，再添加到主屏幕。

提示：公开代码仓库并不意味着你的购物数据公开。数据保存在你的手机本地；不要把导出的 JSON 备份上传进公开仓库。

## 数据安全

iOS 可能在清理浏览器数据、删除主屏幕 App 或存储空间紧张时清除网站数据，建议每周导出 JSON。使用不同浏览器或安装方式可能导致数据存储隔离。
